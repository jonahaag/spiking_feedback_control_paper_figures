# Spiking feedback control: paper figures

Figures and the data behind them for the spiking feedback control paper: DYNAP-SE hardware results
("Dynapse") on the yin-yang and mnist1d datasets, plus simulation baselines.

## Setup

```bash
uv sync
```

`dataset_visualization/` additionally needs `torch` and `torchvision`, which are not part of the
`uv` environment.

## Repository layout

| Path | Contents |
|---|---|
| `dynapse_results/` | Raw hardware runs, one directory per run, named `<seed>_<chip>` (memory-mapped `.dat` metrics + `*.pkl` metadata) |
| `data/dynapse/` | Long-format CSVs extracted from `dynapse_results/` (what the figures read) |
| `data/simulation/` | Simulation results (wandb exports, `;`-separated) |
| `scripts/` | Extraction scripts, plotting helpers (`plotting_utils.py`) and `create_figures.ipynb` |
| `figures/` | Generated figures (`.pdf` + `.png`) |
| `dataset_visualization/` | mnist1d / Poisson-target dataset illustrations (`MNIST1D_vis.ipynb`) |

## Regenerating the figures

All scripts run from within `scripts/`:

```bash
cd scripts
uv run python extract_accuracy_data.py              # -> data/dynapse/{mnist1d,yinyang}_accuracy.csv
uv run python extract_hidden_activity_data.py       # -> data/dynapse/yinyang_hidden_activity.csv
uv run python extract_predictions_data.py           # -> data/dynapse/yinyang_predictions.csv
uv run python extract_weight_distributions_data.py  # -> data/dynapse/{yinyang,mnist1d}_weight_distributions.csv
uv run python extract_feedback_current_data.py      # -> data/dynapse/mnist1d_feedback_current.csv
uv run python extract_population_data.py           # -> data/dynapse/mnist1d_npop2_accuracy.csv, ..._population_archive_accuracy.csv
uv run jupyter nbconvert --to notebook --execute --inplace create_figures.ipynb
```

The extraction step is only needed when raw results change; the notebook only reads `data/`.
`extract_population_data.py` needs the population raw runs, which are kept locally only (see below).
`summarize_runs.py` / `summarize_runs*.ipynb` are standalone summary tables and plots of the raw
runs (not used for the paper figures).

Naming and order (all figures, both datasets): **Frozen** (`frozen/`, regime `frozen`), **DFA**
(fixed random feedback, `fixed_random_feedback/`, regime `fixed-feedback`), **Rec-LRA** (learnt
feedback, `full/`, regime `full`), always in that order and colour (`REGIME_COLOR` /
`REGIME_LABEL` in `scripts/plotting_utils.py`). "Best validation accuracy" is the
maximum over the validation checkpoints of a run; box plots / error bars are over seeds (and
chips where not split by chip).

## Dynapse results

All runs: 3 chips (0, 1, 2) per seed. yin-yang: 75 000 training samples, 15 validation checkpoints;
mnist1d: 50 000 training samples, 10 validation checkpoints.

| Folder | Dataset | Regime | Seeds | n_pop | Used in |
|---|---|---|---|---|---|
| `yinyang/full` | yin-yang | Rec-LRA (learnt feedback) | 201285–201289 (5) | 16 | 2a–f, 4b, 4d |
| `yinyang/frozen` | yin-yang | frozen hidden layer | 201285–201289 (5) | 16 | 2b, 2c, 4b |
| `yinyang/fixed_random_feedback` | yin-yang | fixed random feedback (DFA) | 201285–201287 (3) | 16 | 2c, 4b |
| `mnist1d/full` | mnist1d | Rec-LRA | 201172–201176 (5) | 8 | 3b–f, 4c |
| `mnist1d/frozen` | mnist1d | frozen hidden layers | 201172–201176 (5) | 8 | 3b, 3c, 4c |
| `mnist1d/fixed_random_feedback` | mnist1d | DFA | 201172–201176 (5) | 8 | 3c, 4c |
| `mnist1d/kp` | mnist1d | Kolen-Pollack feedback | 201172–201176 (5) | 8 | not plotted (rows `regime == 'kp'` in `mnist1d_accuracy.csv`) |
| `mnist1d/population_experiments/` | mnist1d | DFA / Rec-LRA with smaller populations | see below | 1–4 | `npop2_training_curves` |

Most tracked run directories contain only the files the loader needs (metric `.dat`s, `*log.pkl`,
`params.pkl`). A few keep extra outputs used by single figures: hidden activity / inputs
(`yinyang/full/2012{85,86}_*`), weights (`yinyang/full/201285_0`, `mnist1d/full/201175_0`) and
outputs (`yinyang/full/201286_2`, `mnist1d/full/201175_0`). `mnist1d/kp` is tracked in full.

### Population experiments (mnist1d, local only)

The raw population runs are **not in git** (ignored in `.gitignore`), only their extracted CSVs and
documentation:

* `dynapse_results/mnist1d/population_experiments/README.md`: run sets, learning rates, original
  folder names.
* `dynapse_results/mnist1d/population_experiments/runs.csv`: one row per run with settings and best
  validation / test accuracy.
* `data/dynapse/mnist1d_npop2_accuracy.csv`: the runs used for plotting, `npop2_dfa` and
  `npop2_rlra` (n_pop=2, 5 seeds × 3 chips each).
* `data/dynapse/mnist1d_population_archive_accuracy.csv`: all other population runs (`run_set`
  column): the n_pop=1–4 sweep with `lr ∝ 1/n_pop`, two n_pop=4 runs with unscaled learning rates,
  and an n_pop=2 Rec-LRA run set with doubled feedback learning rates.

The n_pop=8 reference for the n_pop=2 runs is the main mnist1d data (`mnist1d/{full,fixed_random_feedback}`).

## Caveats

* The x-axis label "Training steps" in 2b, 3b and `npop2_training_curves` counts training samples
  (batch size 20, e.g. 50 000 samples = 2 500 optimisation steps for mnist1d).
* `figures/fig2c_all.*` came with the `version_2` branch; no cell in `create_figures.ipynb`
  regenerates it.
