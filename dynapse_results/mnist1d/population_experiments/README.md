# mnist1d population-size experiments (DFA vs. Rec-LRA)

The raw runs in this folder are **not tracked in git** (see `.gitignore`); they are kept locally
only. Their extracted curves are tracked in `data/dynapse/` and every run is listed in `runs.csv`
(run set, seed, chip, n_pop, learning rates, best validation and test accuracy), regenerated by
`scripts/extract_population_data.py`.

Layout: `<run_set>/<timestamp>/<seed>_<chip>/`, 3 chips (0-2) per seed. Method naming:
DFA = fixed random feedback (`regime` `fixed-feedback`), Rec-LRA = learnt feedback (`regime` `full`).
All settings that are not listed below are identical across run sets apart from seed and chip
(chip 2 always uses `out_offset=100`, as in the main runs).

## Run sets

| Run set | Method | n_pop | Seeds × chips | Learning rates | Used in figures |
|---|---|---|---|---|---|
| `npop2_dfa` | DFA | 2 | 5 × 3 | `lr_out=4e-4`, `lr_hid1=8e-5`, `lr_hid2=1.6e-4` (2× the 1/n_pop rule, i.e. the n_pop=1 rates) | **yes** |
| `npop2_rlra` | Rec-LRA | 2 | 5 × 3 | same forward LRs as `npop2_dfa`; feedback `lr_fb=8e-6`, `lr_fb_hid1=1.6e-5` | **yes** |
| `archive/sweep_lr_scaled_dfa` | DFA | 1, 2, 3, 4 | 1, 5, 5, 1 seeds × 3 | `lr ∝ 1/n_pop` (`lr_out = 4e-4 / n_pop`) | no |
| `archive/sweep_lr_scaled_rlra` | Rec-LRA | 1, 2, 3, 4 | 1, 5, 5, 1 seeds × 3 | `lr ∝ 1/n_pop` (`lr_out = 4e-4 / n_pop`, `lr_fb = 1.6e-5 / n_pop`) | no |
| `archive/npop4_unscaled_lr_dfa` | DFA | 4 | 1 × 3 | n_pop=8 learning rates (`lr_out=5e-5`), i.e. half the 1/n_pop rule | no |
| `archive/npop4_unscaled_lr_rlra` | Rec-LRA | 4 | 1 × 3 | n_pop=8 learning rates (`lr_out=5e-5`) | no |
| `archive/npop2_lr2x_rlra` | Rec-LRA | 2 | 5 × 3 | 2× forward **and** feedback LRs (`lr_fb=1.6e-5`, `lr_fb_hid1=4e-5`) | no |

Also scaled with n_pop in every run set: `WMAX_hid1 = 4·n_pop`, `WMAX_hid2 = WMAX_out = 2·n_pop`,
`sigma_ff = 0.5·n_pop`.

The n_pop=8 reference is the main mnist1d data (`dynapse_results/mnist1d/{full,fixed_random_feedback}`,
`lr_out = 5e-5`), which follows the same `lr ∝ 1/n_pop` rule as the sweep.
